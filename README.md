# Brew Bot

A cafe serving robot in simulation (ROS 2, Gazebo, Nav2). 
**Work in progress, early rough model.**

The robot takes a table order, picks up the tray at the kitchen, delivers it to the table, then returns home.

## Requirements

- Ubuntu 22.04, ROS 2 Humble, Gazebo Fortress (`ros_gz`)
- Nav2 (`navigation2`, `nav2_bringup`, `nav2_simple_commander`)
